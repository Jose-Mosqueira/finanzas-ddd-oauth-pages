Finanzas DDD Respaldos

Aplicación de uso personal para realizar copias de seguridad cifradas de una base de datos PostgreSQL y almacenarlas en Google Drive mediante rclone.

Acceso a Google Drive

La aplicación utiliza el permiso drive.file para crear y administrar los archivos de respaldo que genera.

Privacidad

Los respaldos se cifran antes de transferirse a Google Drive. La clave de cifrado no se publica en este sitio.
